# Generated Icon Assets

This directory contains deterministic preview output from `scripts/icons/generate-icons.py`.

Generated firmware masks live in `src/ui/assets/IconBitmaps.h` and
`src/ui/assets/IconBitmaps.cpp`. Re-run the generator after changing SVG sources in
`assets/icons/source/`.

The firmware build uses checked-in generated C++ files and does not require SVG or image tooling.
