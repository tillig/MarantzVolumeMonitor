# 3D Printable Box for Volume Monitor

These are the models I used for the box I have my volume monitor project in.

Print both with the large flat side on the print bed. No supports are required.

To attach things you'll need...

- Screen: 4 x M3*6 screws
- ESP32: 4 x M2.6*6 screws
- Box top to box bottom: 4 x M2.6*10 screws

You can potentially fudge the screw sizes given it's just plastic. There wasn't science behind the sizes I picked, I just happened to have them. [This is the set of screws I have.](https://amzn.to/4avfLJj)
