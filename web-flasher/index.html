Flash the Marantz Volume Monitor

This installs the latest firmware release onto an Elegoo ESP32 DevKit V1 directly from your browser. No build tools or command line are needed.

Use a desktop version of Chrome or Edge. This page relies on Web Serial, which Firefox, Safari, and mobile browsers do not support.
  1. Connect the ESP32 to this computer with a USB data cable.
  2. Select Connect and Install and choose the ESP32's serial port when the browser asks.
  3. When asked whether to erase the device, leave Erase device unchecked to keep your Wi-Fi, receiver, and touch calibration settings. Check it only to start over.
  4. Wait for the install to finish. The monitor restarts and shows setup on its touchscreen if it is new.

Your browser does not support Web Serial. Use desktop Chrome or Edge. Serial access was blocked. Allow it and reload the page.
