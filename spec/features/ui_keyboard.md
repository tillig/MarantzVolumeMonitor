# Feature: On-Screen Keyboard

## Modes

- QWERTY (letters + punctuation + symbols)
- Numeric (for IP entry)

## Requirements

- Touch targets ≥ 48×48 px
- Enter, Backspace, Space keys
- Mode switch between:
  - QWERTY
  - Numeric
  - Symbols/Punctuation

## Punctuation & Symbols

The keyboard must support strong-password characters, including:

! @ # $ % ^ & * ( ) - _ = + [ ] { } ; : ' " , . / ? \ | ~ `

## Behavior

- QWERTY mode includes letters + a “Symbols” key.
- Symbols mode replaces the letter rows with punctuation/symbols.
- Numeric mode is used for IP entry and includes:
  - Digits 0–9
  - Dot (.)
  - Backspace
  - Enter
