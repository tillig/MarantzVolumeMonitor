# Feature: Home Screen UI

## Purpose

Display real-time receiver information in a readable, calm, dark-mode UI.

## Elements

- Large volume number (72–96 px)
- Horizontal volume bar
- Source text
- Mode text (exact string from receiver)
- Audio family tiles:
  - Dolby
  - DTS
  - PCM
  - Other (always visible)
- Settings gear icon

## Behavior

- Volume animates only when changed.
- Tiles highlight based on mode family.
- No idle animations.
